# Password Encryption System

**Privacy by Design. Security by Purpose.**

## Project Overview
The Password Encryption System is a Java desktop application developed using Java Swing and MySQL. It provides user registration, login authentication, password strength checking, and random password generation.

## Features
- User registration and secure login
- Password strength checker
- Random password generator
- Password hashing using PBKDF2-HMAC-SHA256
- MySQL database integration using JDBC
- Login activity tracking

## Technologies Used
- Java (JDK 11 or later)
- Java Swing
- MySQL
- JDBC (MySQL Connector/J)
- PBKDF2-HMAC-SHA256

## Requirements
- JDK 11 or later
- MySQL Server
- MySQL Connector/J

## Database
The database is designed to store user details, hashed password records, and login activity.

## Project Objective
To demonstrate password security, user authentication, Java GUI development, and database connectivity.

## Future Enhancements
- Password reset functionality
- Email verification
- Improved security and user interface

## Project Status
Academic project for learning password security, Java programming, and MySQL integration.
